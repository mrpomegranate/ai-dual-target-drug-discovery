# Curated EGFR/HER2 data

Place the unchanged `curated_egfr_her2.csv` copied from the Assignment 10 submission into this directory. Its 9,779 molecule records comprise 8,692 frozen training and 1,087 scaffold-held-out validation records. The locked test is excluded. Each row carries structure, scaffold group, partition, target masks and accepted pIC50 labels.

The file is excluded from public Git to avoid uncontrolled redistribution of a curated BindingDB excerpt. Include it in the controlled Google Drive course submission only as permitted, or include acquisition/curation instructions and source attribution. Do not infer missing labels as inactive.
